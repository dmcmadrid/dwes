# Z_pruebas

Carpeta libre para pruebas, ideas y adelantar temario. No son ejercicios del profesor.

- Crea una subcarpeta por cada prueba o tema (por ejemplo: abstractas, herencia...).
- Cuando ya no la necesites, bórrala.
- Se sube a GitHub como el resto: lo que borres aquí y subas con push
  también se borrará en el otro ordenador al hacer pull.
